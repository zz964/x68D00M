x68D00M - Doom for Sharp X68000
================================

File Manifest
-------------


BUILD SYSTEM
  makefile.x68k              Main build makefile (68060 and 68030 targets)
  Makefile                   Original Linux makefile (reference only)
  xmakefile                  Original X68000 makefile (reference only)


X68000 PORT - Core
  i_main.c                   Entry point, supervisor mode setup
  i_system.c / .h            System interface: timing, memory, CPU detection
  i_video.c / .h             Video: CRTC mode setup, GVRAM blitting, keyboard
  i_sound.c / .h             Sound: ADPCM, Mercury Unit PCM8PP, SFX conversion
  i_net.c / .h               Network stub
  i_prof_timer.c / .h        High-resolution profiling timer
  display.c / .h             Legacy display init (retained from original port)
  serial.c / .h              Serial debug output

X68000 PORT - Hardware Abstraction
  crtc.c / .h                CRTC register definitions and pointers
  cynthia.c / .h             Cynthia (sprite/BG controller) registers
  vc.c / .h                  Video controller registers
  mfp.c / .h                 MFP (Multi-Function Peripheral) registers
  tvram.c / .h               Text VRAM access
  irq.c / .h                 IRQ/interrupt handler infrastructure
  dmac.h                     HD63450 DMA controller register definitions

X68000 PORT - Optimized Rendering
  r_draw_asm.S               Hand-optimized 68060 assembly:
                               R_DrawColumn (3-pixel unrolled, BFEXTU)
                               R_DrawSpan (ADDX+SWAP interleave)
                               FixedMul/FixedDiv (FPU, 68060 only)
                               R_MapPlane/R_DrawPlanes (inline FPU, 68060 only)
                               I_BlitBlock, I_BlitCopy16 (GVRAM blitters)
                               I_CachePushAll (68060 cache flush)

X68000 PORT - Music
  opm_music.c / .h           YM2151 OPL2-to-OPM patch conversion and playback
  mus_player.c / .h          MUS format parser, OPM timer-driven ISR player
  midi_out.c / .h            External MIDI output (YM3802 UART)
  gm_opm_patches.h           Embedded GM patch bank (FB-01 factory presets)
  gm.opm                     GM patch bank in VOPM text format (reference)

X68000 PORT - Sound Effects
  adpcm_enc.c / .h           OKI ADPCM encoder for SFX conversion

X68000 PORT - Fixed Point
  m_fixed.c / .h             FixedMul/FixedDiv: C (68030) or asm FPU (68060)
  mfixed000.S                68000 fixed-point asm (reference, unused)
  mfixed020.S                68020 fixed-point asm (reference, unused)

X68000 PORT - Profiling
  doom_perf.c / .h           Per-frame performance counters
  doom_log.c / .h            File-based debug logging

X68000 PORT - Stubs
  missing.c                  Stubs for missing libc functions
  wmissing.c                 Additional missing function stubs
  values.h                   Numeric limits for X68000 compiler
